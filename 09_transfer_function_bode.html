1. 전달함수 H(s) 유도

운동방정식 m·u'' + c·u' + k·u = p(t) 에 라플라스 변환을 적용하면, 초기 정지 상태에서 H(s) = U(s)/P(s) = 1/(ms² + cs + k) 입니다. 정적 변위 ust = p₀/k 기준 무차원화 시 H(s) = ωn² / (s² + 2ζωns + ωn²) 이 됩니다.

2. 공진 시 90° 위상차의 본질

공진(β = 1.0)에서는 질량 관성력(-mω²u)과 탄성 복원력(ku)이 크기는 같고 방향이 정반대가 되어 완전 상쇄됩니다. 따라서 외력 p(t)는 오직 점성 감쇠력 c·u'(t)하고만 평형을 이루며, 속도와 외력이 완벽히 동위상(변위와 90° 직교)이 됩니다.

3. 고주파 방진절연 (β > √2)

가진 주파수가 고유주기보다 충분히 높은 영역(β > 1.414)에서는 질량의 관성이 지배하여 진폭 전달률 |H| < 1 (0 dB 이하)로 급감하며, 고주파 점근선 기울기는 -40 dB/dec (1/ω² 비례 감쇠)를 나타냅니다. 이것이 기계 기초 및 건물의 진동 절연(Isolation)의 기본 원리입니다.

4. s-평면 극점과 댐퍼 설계

구조물에 점성 댐퍼(Toggle/Linear Viscous Damper)를 추가하면 등가 감쇠비 ζ가 상승하여 복소 극점의 실수부(-ζωn)가 음의 축 방향으로 깊숙이 이동합니다. 이는 자유진동 및 지진 충격 시 응답 포락선의 감쇠 감쇄율을 기하급수적으로 가속화하여 안전성을 극대화합니다.
